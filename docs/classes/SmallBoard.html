    Class SmallBoard

    Represents a single 3×3 Tic Tac Toe board.

    A SmallBoard is the fundamental building block of the Ultimate Tic Tac Toe game. Each instance maintains its own 3×3 grid of Mark values and is responsible for:

    • Storing cell state
    • Validating placements
    • Detecting local winners
    • Detecting full-board (draw) conditions

    Design Notes

    • Internally mutable: place() modifies the board state.
    • Externally treated as immutable at the UltimateBoard level (cloning is used before mutation).
    • All cell access is range-checked.

    Coordinate System

    Rows and columns are indexed from 0 to 2.

    (0,0) (0,1) (0,2)
    (1,0) (1,1) (1,2)
    (2,0) (2,1) (2,2)

    Marks

    Each cell contains a Mark:

    • "X"
    • "O"
    • "." (empty)

    constructor

    • new SmallBoard(): SmallBoard

      Creates a new empty 3×3 SmallBoard.

      All cells are initialized to "." (empty).

      Invariant established:

      • The grid is exactly 3 rows
      • Each row contains exactly 3 columns
      • Every cell contains a valid Mark

      This constructor does not accept external input to ensure the internal structure of the board is always valid.

      Higher-level game logic relies on this invariant when cloning and composing boards inside UltimateBoard.

      Returns SmallBoard

    • getWinner(): Mark | null

      Determines whether this board has a winner.

      A player wins if they have three identical non-empty marks in a row, column, or diagonal.

      Returns Mark | null

      • "X" if X has won
      • "O" if O has won
      • null if there is currently no winner
